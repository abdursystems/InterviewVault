# EXACT ADMIN BACKEND API CONTRACTS (MATCH EVERY FIELD NAME & STATUS CODE)
All routes below require `Authorization: Bearer <token>` and `role === "Admin"`:

1. **Topics (Read-Only):**
   - `GET /api/admin/topics` -> returns `[{ _id, name }]` (sorted alphabetically: DBMS, DSA, OOP, OS).

2. **Subtopics (UC-15):**
   - `GET /api/admin/subtopics?topicID=` -> returns `[{ _id, name, topicID: { _id, name } }]`.
   - `POST /api/admin/subtopics` -> body: `{ topicID, name }` -> returns `201` created subtopic. Handle `409` (`"Subtopic already exists in this topic"`).
   - `PUT /api/admin/subtopics/:id` -> body: `{ name }` -> returns updated subtopic. Handle `409` duplicate name error.
   - `DELETE /api/admin/subtopics/:id` -> returns `{ deleted: true }`. Handle `409` (`"Cannot delete: X question(s) use this subtopic"`).

3. **Question Bank (UC-16 / FR-5 / FR-11):**
   - `GET /api/admin/questions` -> query params: `topicID`, `subtopicID`, `difficulty` ("Easy"|"Medium"|"Hard"), `type` ("Theory"|"Coding"), `archived` ("true"|"false"|""), `q` (search string), `page` (default 1), `limit` (default 20, max 100) -> returns:
     `{ items: [{ _id, statement, topicID: { _id, name }, subtopicIDs: [{ _id, name }], difficulty, type, modelAnswer, testCases: [{ input, expectedOutput, isHidden }], isArchived, createdAt }], total, page, pages }`.
   - `GET /api/admin/questions/:id` -> returns full single question object INCLUDING hidden `testCases` and `modelAnswer` for editing.
   - `POST /api/admin/questions` -> body: `{ statement, topicID, subtopicIDs, difficulty, type, modelAnswer, testCases }` -> returns `201` created question.
     - **Strict Validation:** `subtopicIDs` must contain **1 to 3** subtopics belonging to the selected `topicID`. If `type === "Theory"`, `modelAnswer` is required. If `type === "Coding"`, at least 1 test case with non-empty `expectedOutput` is required (`{ input, expectedOutput, isHidden }`).
   - `PUT /api/admin/questions/:id` -> same body as POST -> returns updated question.
     - **Handle `409` Integrity Guard:** If `subtopicIDs` were modified on a question that already has student attempts, surface the backend's `409` message clearly in an inline alert banner inside the modal (`"This question already has attempts, so its subtopic tags cannot change. Archive it and create a new question instead."`).
   - `DELETE /api/admin/questions/:id` -> returns either `{ deleted: true }` OR `{ archived: true, message: "Question is in use, so it was archived instead of deleted" }`. Show a distinct toast explaining whether the question was permanently deleted or archived!
   - `POST /api/admin/questions/:id/restore` -> unarchives a question (`isArchived: false`) and returns the restored question.

4. **User Accounts (UC-17):**
   - `GET /api/admin/users` -> returns `[{ _id, name, email, role: "Student"|"Admin", isActive: boolean, profileImageUrl, createdAt }]` (never expects password fields).
   - `PUT /api/admin/users/:id/role` -> body: `{ role: "Student"|"Admin" }` -> returns updated user.
   - `PUT /api/admin/users/:id/active` -> body: `{ isActive: true|false }` -> returns updated user.
   - `DELETE /api/admin/users/:id` -> returns `{ deleted: true }`. Handle `409` (`"This user has attempts. Disable the account instead of deleting it."`).
   - **Self-Protection UX:** Identify the currently logged-in admin (`row._id === currentUser._id`) with a `"You"` badge and disable the role change, deactivate, and delete buttons on their own row (matching the backend's `400` self-protection guard).

5. **Anonymized Analytics Export (DFD Process 7.0):**
   - `GET /api/admin/export` -> returns:
     `{ exportedAt, summary: { uniqueUsers, totalAttempts, totalSubtopicStatRecords }, subtopicStats: [{ anonymousUserId, topic, subtopic, solved, attempted, skipped, lastPracticed }], attempts: [{ anonymousUserId, questionId, topic, subtopics, difficulty, type, status, timeTakenSeconds, createdAt }] }`.
